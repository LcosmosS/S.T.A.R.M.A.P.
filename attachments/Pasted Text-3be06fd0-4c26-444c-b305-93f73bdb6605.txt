[

[

[

[

]

and a closed two-form

[

We require, for a genuinely topological sector,

[

[

\frac12F_{Q\mu\nu}dx^\mu\wedge dx^\nu,

[

\omega_{AB}(Y)

Because

[

[

The topological charge is therefore defined on a closed two-cycle \Sigma_2\subset M by

\boxed{

If \Sigma_2 represents a nontrivial homology class, this gives the pairing

[

\langle[\omega],[\Sigma_2]\rangle.

This is consistent with the ECC treatment of entropy flux as a cohomological fingerprint.

The important distinction is

[
\boxed{

versus the local scalar

[
\boxed{

\frac14F_{Q\mu\nu}F_Q^{\mu\nu}.

The former is topological; the latter is a local dynamical scalar.
